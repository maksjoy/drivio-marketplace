# Security policy

## Supported versions

Security fixes land on `main`. That branch is what production deploys.

## Reporting a vulnerability

Report a vulnerability privately with a GitHub Security Advisory:

https://github.com/maksjoy/drivio-marketplace/security/advisories/new

Use that form instead of a public issue, pull request, or discussion. Describe what is affected, how to reproduce it, and the impact if you know it.

The same advisory URL is the contact published at `/.well-known/security.txt` on the public site. There is no separate security email address.
